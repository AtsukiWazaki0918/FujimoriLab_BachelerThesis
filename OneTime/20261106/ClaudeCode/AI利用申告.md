## 1. モデル間比較の図（2026年11月6日）

- **使用ツールと期間**：Claude（Anthropic）。claude.ai 上で、作成者の PC のフォルダにつないで作業した。設定上のモデルは claude-opus-5-5（実際に応答したモデルは異なる可能性がある）。使用日は 2026年11月6日。
- **使用目的と対象**：AgMIP 形式の5モデルの出力（CSV）と AIM-ALPHA の2050年の効果を比べるために使った。対象はプログラム（`prog/figCSV_compare.py`）、図21枚、数値の表3つである。途中の版（Excel を使ったもの）のプログラム・図・表は `others/excel_version/` にある。
- **作成者が指示・決定した内容**：
  - Excel をやめて CSV だけで作り直すことを決めた。
  - 指標を生産量（カロリーベース）、生産者価格（2020年の Baseline に対する2050年の価格指数）、消費量（カロリーベース、CONS）にすることを決めた。
  - 地域を世界と AgMIP の17地域にし、AIM-ALPHA の集計に `cty_reg_map` を使うことを決めた。
  - 作物を、畜産と加工品を除いた CRP と、5作物（WHT, RIC, CGR, OSD, SGC）にすることを決めた。
  - 卒論の4つの効果で示すこと、AIM-ALPHA 以外のモデルの中央値を棒で示すことを指示した。
  - カロリー換算は世界で1つの係数（作物ごと）を全モデルに使い、AIM-Hub の OCR には VFN＋OCR の係数を使うことを決めた。
  - 価格は、その年の生産量（重量）で重み付けすることを決めた。
  - 台湾は AIM-ALPHA に含まれていない（人口・GDP の将来推計が無いため）ことを確認した。
  - AIM-ALPHA の wO3 の扱いを確認し、AI の確認結果を受けて `_W_CH4` なしで作り直すことを了承した。
  - GCAM のトルコについて注釈に書き、EUR・MEN・AME で GCAM を中央値から外すことを決めた。
  - 欠損の注釈を、AIM-ALPHA で計算されていない国だけにし、地域の人口（2015年）に占める割合を書き、該当するパネルに † を付けることを決めた。
- **AI が調べて示した内容**：
  - 各モデルの CSV の変数・品目・単位・地域・シナリオを調べ、作れる図の範囲を示した。
  - AIM-ALPHA で値が無い国を、計算されていない国（2015年までしか値が無い）と、生産が無い国（BHR, QAT, BTN）に分けた。
  - 各モデルの地域の人口から、欠けているのが AIM-ALPHA だけであること、GCAM ではトルコが EUR に入っていることを推定した。
  - `impact_cty.map` から、台湾の生産が CHN に含まれることを示した。
  - `_W_CH4` の有無による効果の違いの大きさを示した。
  - AIM-ALPHA の外生収量のオゾンの影響を各モデルの CSV と比べ、`_W_CH4` なしと一致することを示した。
  - AIM-ALPHA の CHN のオゾンの影響が 0 であることを見つけた（未対応）。
- **AI が決めた内容**（作成者の確認の対象）：
  - カロリー換算係数の計算方法（cal_load ÷ qdFood_load、2020年、Baseline）と単位（PJ）。
  - 図の形（世界は指標ごとに1枚・6パネル、17地域は指標×品目ごとに1枚）と、注釈の文言。
  - Excel 版の図とプログラムを `others/excel_version/` に移した。
- **AI が行った検証**：
  - 自分で作った CRP の価格が、AIM-Hub の CSV の CRP の価格と一致することを確かめた。
  - 5つの値をプログラムとは別のコードで計算し直し、一致を確かめた。
  - (1)＋(2)＝(3) と、GCAM を除いた中央値を確かめた。
  - 図を目で見て、注釈やラベルが切れたり重なったりしていないことを確かめた。
- **本人による確認状況**：台湾の扱いは作成者が研究室に確認した。メタンについては、GHG としての排出は計算しているが収量への影響は不明、との回答を得ており、AI のデータでの確認結果に基づいて図を作った。図は作成者が確認したうえで GitHub に上げる予定である。最終的な内容と判断の責任は作成者が負う。
